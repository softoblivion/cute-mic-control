## ⪩ Mic Control v1.0.0 ⪨

First release: a tray microphone toggle with a global hotkey and a heart indicator on the desktop.

---

### ⤷ Added ˎˊ˗

- Global microphone toggle for the default Windows input device.
- Animated desktop heart indicator:
  - Whole heart when the microphone is enabled.
  - Broken heart when the microphone is muted.
  - Dimmed heart when the input device is unavailable.
- Pulse glow animation around the active heart.
- Configurable keyboard shortcuts:
  - Single keys.
  - Ctrl, Alt, Shift, and Win modifiers.
  - Function keys.
  - Navigation keys.
  - NumPad and Num Enter.
  - Media keys.
  - OEM keys.
  - Left and right modifier keys.
- English settings interface with:
  - Shortcut recording.
  - Keyboard key search.
  - Indicator visibility control.
  - Indicator size from 50% to 200%.
  - Launch-at-login option.
- Five prepared color palettes:
  - Nebula.
  - Aurora.
  - Glacier.
  - Ember.
  - Lunar.
- System tray integration:
  - Toggle microphone.
  - Open settings.
  - Quit the application.
- Automatic settings persistence.
- Portable Windows build with no external package installation required.
- Built-in self-test mode for:
  - Keyboard input.
  - Audio control.
  - Settings persistence.
  - Appearance settings.
  - UI rendering.
