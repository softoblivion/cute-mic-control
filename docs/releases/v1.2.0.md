## ⪩ Mic Control v1.2.0 ⪨

Mic Control now checks for updates every 5 minutes instead of every 6 hours.

---

### ⤷ Changed ˎˊ˗

- **Update check every 5 minutes** — the app checks this repository's releases on every start and then every 5 minutes while it runs, also while the window is hidden in the tray. With **Download updates automatically** on (the default) a found version is downloaded at once; it is installed only when you choose **Restart to update**.
- **Back-off after a failed check** — the wait before the next check doubles after every failure (10, 20, 40, up to 60 minutes) and returns to 5 minutes after the next check that succeeds.
- **No check without a network** — nothing is requested while Windows reports no network connection, and a skipped check does not count as a failure.
