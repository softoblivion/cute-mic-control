## ⪩ Mic Control v2.1.0 ⪨

A new version now opens its own window with the release notes, so an update is seen when it arrives and installed
with one click.

---

### ⤷ Added ˎˊ˗

- **Update window** — opens by itself when the update check finds a new version: "Mic Control X.Y.Z", the installed
  version, the download size and the release date, and the notes of the release (headings, lists, bold text, code,
  links that open in the browser). It works while Settings is hidden in the tray and follows the window theme.
- **Install** downloads the new version, shows the progress ("42% · 5.1 MB of 12.1 MB") and restarts into it as soon
  as the file is verified. When the version was already downloaded automatically, the button reads **Restart to
  update**; after a failed download it reads **Try again**.
- **Later** (or Esc) closes the window; it does not open again by itself for that version until the app restarts.
  The tray menu item and the update button in Settings open it again.

### ⤷ Changed ˎˊ˗

- The update check reads the release notes, the size and the date from GitHub. When GitHub limits these requests,
  the check falls back to the plain version check of earlier releases and the window shows "No release notes for
  this version."
- The "ready" notification now appears only when a background download finishes while the update window is closed.
