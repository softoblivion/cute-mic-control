## ⪩ Mic Control v2.2.0 ⪨

A cleaner, more compact window in the shared look of the softoblivion apps, with a new Scale setting that makes the window and its text larger on high-resolution screens.

---

### ⤷ Added ˎˊ˗

- **Scale** — under Appearance in Settings: 100, 125, 150, 175 or 200 % on top of the Windows display scaling. The window and everything in it grow together and stay sharp; the choice is saved and applied before the window opens. Steps that would not fit the screen are dimmed.
- **Title bar** — the app icon, the name and the version on the left; one capsule with Settings, Minimize and Close on the right. The version shows a dot while an update is available (mint when it is ready to install); a click checks for updates or opens the update window.
- **Settings sheet** — the gear opens Appearance (indicator size, theme, colour palette, scale), General (launch at login) and Updates; the main window keeps the heart, Mute, the hotkey and the indicator switch. Esc, the close button or the gear close it.

### ⤷ Changed ˎˊ˗

- New typeface: Sora for all text and Geist Mono for the version and key names, embedded in the app, so the window looks the same on every PC. Text sizes follow one fixed scale shared with the other apps.
- Compact layout: smaller controls and tighter spacing; the window is 396 x 524 at 100 %.
- The update window uses the same typeface, close button and scale.
- The update engine is now a library shared with other apps; its behaviour is unchanged (check every 5 minutes, a longer wait after failed checks, no check while offline, verified download, one-click install).
- The exe is about 330 KB (the embedded fonts).
