## ⪩ Mic Control v2.4.0 ⪨

Larger text and a taller title bar, so the window reads comfortably on a large monitor at 100 % display scaling.

---

### ⤷ Changed ˎˊ˗

- **Text size** — every text style is one step larger: body text 14 px instead of 13, labels and buttons 13.5, headings 17, captions 12.5, the key search field 13. Weights and line spacing stay the same.
- **Title bar** — 52 px instead of 44: a larger heart glyph, the app name in the heading size, a taller version pill and larger Settings, Minimize and Close buttons; the close buttons of Settings, the hotkey editor and the update window match them.
- **Theme chips** — the four theme names fit on one row at the larger size.
