## ⪩ Mic Control v2.3.0 ⪨

The update notice now follows the same rules as the other softoblivion apps; the update window looks as before.

---

### ⤷ Changed ˎˊ˗

- The **Download** button in Settings → Updates downloads the new version right away, and **Restart to update** there
  restarts into it; before, both opened the update window. The version in the title bar and the tray menu item still
  open the window while a new version is known.
- The tray menu has one update item that follows the update (**Check for updates**, **Download**, **Downloading…**,
  **Restart to update**, **Try again**) instead of two.
- The update status line in Settings reads "You have the latest version", "Version X.Y.Z is available", "Downloading
  version X.Y.Z…" or "Version X.Y.Z is ready to install"; the tooltip of the version in the title bar names the new
  version while one is known.
- Release notes open only `https` links in the browser; other link targets stay plain text. A link that cannot be
  opened shows a notification.
- **Install** pressed while a check is still running now starts the download as soon as the check finds the version.
- The wait between update checks varies by up to 30 seconds either way, so apps started together do not all ask GitHub
  at the same moment.
- **Try again** after a failed download downloads again and waits for **Restart to update**, instead of restarting by
  itself when the file is verified.
